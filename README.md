With the migration of More Traits into Evolving Traits World, a not-insignificant chunk of the traits within MT were lost due to creative differences or time constraints, bricking in-progress saves.

While those saves sadly can't be recovered to my knowledge, this repository/mod is a stopgap to restore the functionality of MT prior to migration by reverting the changes made for migration.

I'm not a coder, I barely know how to code, and I refuse to use Claude or any other godforsaken LLM to code for me, so don't expect this to be updated very often.

This is not my code, and it should not be treated like my code.
